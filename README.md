# Full Stack Open Exercises

This repository contains my solutions and projects for the **Full Stack Open** course offered by the **University of Helsinki**.

## About the Course

Full Stack Open is a comprehensive web development course focused on modern JavaScript application development. The curriculum emphasizes building full-stack applications using React for the frontend and Node.js for the backend.

- **Course Provider:** University of Helsinki
- **Credits Earned:** 7 ECTS
- **Grade:** 5

## Topics Covered

- React
- JavaScript (ES6+)
- Component-based architecture
- React Hooks
- React Router
- State Management
- REST APIs
- Node.js
- Express.js
- MongoDB
- Mongoose
- User Authentication
- Testing
- Deployment
